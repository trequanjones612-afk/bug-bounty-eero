# Notes

`notes/` is for private working notes: inventory reminders, questions to re-read on the live policy, and links you want next to the checklist.

Do not put live finding details here while this repository is public. A result that describes a real issue belongs in a private HackerOne report, using [../reports/TEMPLATE.md](../reports/TEMPLATE.md), and nowhere else until eero has fixed it and allowed disclosure.

`notes/private/` is listed in `.gitignore`. Use that directory on your own machine for anything you would not want on a public GitHub page. Gitignore is a backstop. Making the repository private is the actual control. See the warning in [../README.md](../README.md).

This directory starts empty on purpose.
